# 地学文献工作台

Windows 地学文献管理、PDF 阅读、Word 引文和保留排版翻译。

## 下载与安装

**[下载最新版本](https://github.com/pearr6226-cpu/GeoRefWorkbench-Releases/releases/latest)**

在最新发行版的 Assets 中下载 `GeoRefWorkbench-版本号-win-x64.zip`，完整解压，保存并关闭 Word 和旧版工作台后运行 `Install.cmd`。

## 以后如何更新

从 1.7.0 起，进入 **设置 → 关于 → 检查更新**，可以查看新版本和更新说明，选择下载、安装并重启。也可开启自动检查：发现新版才提示，由用户决定是否更新。

初次安装完成后，只需在工作台内更新；不用再找同学转发安装包。离线不会影响文献库使用。

## 这个仓库包含什么

这里只发布安装包、更新说明和签名更新清单，不包含软件源码、用户文献库、PDF 或个人配置。GitHub 自动显示的 Source code 归档只有本说明文件，不是安装程序。
